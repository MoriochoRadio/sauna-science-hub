# 사우나 사이언스 허브 (Sauna Science Hub)

사우나가 인체에 미치는 과학적 근거를 모은 **증거 기반 아카이브**다.
[PubMed](https://pubmed.ncbi.nlm.nih.gov/)에서 매일 자동 수집되는 peer-reviewed 연구·임상시험을
주제와 근거 수준별로 정리한다. 제목·초록은 기계번역 한국어와 원문을 함께 싣는다.

🔗 **라이브**: https://moriochoradio.github.io/sauna-science-hub/

## 무엇을 보여주나

- **90여 편의 사우나·온열요법 연구** — 심혈관, 사망률, 인지, 대사, 회복, 정신건강, 통증·염증 등
- **근거 수준 표시** — 출판 유형별 RCT·임상시험·메타분석·코호트를 1~5급으로 라벨링. ★는 1급(가장 높은 근거)
- **한국어 번역 + 원문 토글** — 기계번역 한국어와 영문 초록을 함께 제공, 버튼으로 전환
- **정기 간행물 형태의 리스트** — 연도·권호 중심의 에디토리얼 레이아웃, 초록은 기본 접힘(클릭해 펼침)

## 기능

| 기능 | 설명 |
|------|------|
| 검색 | 제목·초록·저널·저자 실시간 검색 (검색어 하이라이트) |
| 주제 필터 | 심혈관·사망률·인지·대사·호흡기·회복·정신건강·통증·염증 |
| 근거 필터 | RCT / 임상시험 / 메타·고찰 / 관찰연구 |
| 정렬 | 최신순 · 근거 수준순 · 임상시험 우선 |
| 보기 설정 | 원문(EN) ↔ 한국어, 라이트/다크모드 (로컬 저장) |

## 어떻게 만들어졌나

- **수집**: PubMed E-utilities (키 없이 무료). `scripts/collect.py`가 매일 실행된다.
- **번역**: 키 없는 기계번역으로 한국어 제공. 번역값은 `data/translations.json`에 캐시돼 재번역·rate-limit을 피한다.
- **빌드**: `scripts/build.py`가 `data/research.json`을 읽어 완성된 정적 `index.html`을 만든다 (브라우저 파싱 없음).
- **배포**: GitHub Pages. `daily.yml` 워크플로우가 매일 KST 10:17에 수집→빌드→배포하고, push 시에도 재배포된다.

## 파일 구조

```
sauna-science-hub/
├─ .github/workflows/daily.yml   # 매일 자동 수집·빌드·배포
├─ scripts/
│  ├─ collect.py                  # PubMed 수집 + 한국어 번역(캐시)
│  └─ build.py                   # 정적 사이트 생성기
├─ data/
│  ├─ research.json              # 수집된 논문 메타데이터
│  └─ translations.json          # 번역 캐시
├─ index.html                    # 빌드 결과 (자동 생성)
└─ README.md
```

## 면책

교육·정보 목적이며 의학적 조언을 대체하지 않는다. 사우나 이용은 건강 상태에 따라
전문의와 상담하라. 번역 품질은 참고용이며 정확한 내용은 원논문(PubMed) 링크를 확인하라.
